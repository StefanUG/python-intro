I denne lektion skal du bygge dit eget spil fra bunden: **Gæt et tal**. Computeren vælger et hemmeligt tal, og du skal gætte, hvilket tal det er.

Du skal ikke bruge bien, høstmanden eller labyrinter denne gang. Det er kun dig og Python.

## Sådan ender det

Prøv det færdige spil her. Skriv et tal og tryk Enter:

```python.run hidecode="true"
import random

def get_numeric_guess():
    guess = ""
    while not guess.isnumeric():
        guess = input("Dit gæt: ")
        if not guess.isnumeric():
            print("Det er ikke et tal, prøv igen.")
    return int(guess)

secret = random.randint(1, 100)
print("Jeg tænker på et tal mellem 1 og 100.")

found = False
while not found:
    guess = get_numeric_guess()

    if guess == secret:
        print("Rigtigt! Du fandt tallet!")
        found = True
    elif guess < secret:
        print("Tallet er højere.")
    else:
        print("Tallet er lavere.")
```

## Det skal du lære

Hver side lærer dig én ting, som du lægger til dit spil:

1. **Print** - vis beskeder til spilleren
2. **Input** - spørg spilleren om noget
3. **Stol aldrig på input** - tjek, at spilleren skriver et tal
4. **While og funktioner** - spørg igen, indtil svaret er et tal
5. **Spilløkken** - spørg igen og igen om nye gæt
6. **Betingelser** - er gættet rigtigt, for højt eller for lavt?
7. **Tilfældige tal** - lad computeren vælge tallet

Bagefter er der nogle **valgfri ekstra-opgaver** til dem, der vil lege videre.

## Sådan arbejder du

Nederst på hver side finder du en kodeboks. Det er **den samme kodeboks på alle siderne**. Det du skriver på én side, er stadig der, når du går videre til næste side.

Så bliver dit spil lidt bedre for hver side. Læs siden, forstå ideen, og ret så i din egen kode, så den bruger det nye.

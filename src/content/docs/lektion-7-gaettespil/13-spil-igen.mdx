Lige nu starter du et nyt spil ved at trykke på **Kør kode** igen. Det er helt fint! Men det kan også være rart, hvis spillet selv spørger, om du vil spille en gang til.

## Endnu en løkke uden om

Idéen er den samme som før: en løkke med en variabel, der fortæller, om vi er færdige. Denne gang bruger vi en ydre løkke, der omslutter hele spillet:

```python
play_again = True
while play_again:
    # ... hele spillet ligger her ...

    answer = input("Vil du spille igen? (j/n) ")
    if answer != "j":
        play_again = False
```

`!=` betyder "er **ikke** ens". Hvis svaret ikke er `j`, bliver `play_again` sat til `False`, og løkken stopper.

## Nyt tal hver gang

Når spillet starter forfra, skal computeren vælge et **nyt** hemmeligt tal, og spillet skal være klar til at blive gættet igen. Det betyder, at alt, der skal nulstilles - for eksempel `secret` og `has_guessed_correctly` - skal stå **inde i** den ydre løkke.

:::tip[Opgave]
Ret din kode i kodeboksen nederst:

1. Lav en ydre løkke med variablen `play_again`.
2. Flyt selve spillet ind i løkken (ryk det ind). Navnet og velkomstbeskeden kan godt stå uden for.
3. Spørg til sidst, om spilleren vil spille igen.

Tjek: Får du et nyt tal hver gang? Starter det nye spil forfra?
:::

```python.run
# Byg et 'Gæt et tal'-spil med det, du har lært ovenfor.
# Skriv din egen kode her
```

:::tip[Hint]
`secret = random.randint(1, 100)` og `has_guessed_correctly = False` skal stå inde i den ydre løkke, før den indre `while not has_guessed_correctly:`. Ellers er spillet allerede færdigt, når du spiller anden gang.
:::

<Solution>

```python.run
import random

def get_numeric_guess():
    guess = ""
    while not guess.isnumeric():
        guess = input("Hvad gætter du på? ")
        if not guess.isnumeric():
            print("Det er ikke et tal, prøv igen.")
    return int(guess)

player_name = input("Hvad hedder du? ")
print(f"Velkommen til Gæt et tal, {player_name}!")

play_again = True
while play_again:
    print("Jeg tænker på et tal mellem 1 og 100.")
    secret = random.randint(1, 100)

    has_guessed_correctly = False
    while not has_guessed_correctly:
        guess = get_numeric_guess()

        if guess == secret:
            print("Rigtigt! Du fandt tallet!")
            has_guessed_correctly = True
        elif guess < secret:
            print("Tallet er højere.")
        else:
            print("Tallet er lavere.")

    answer = input("Vil du spille igen? (j/n) ")
    if answer != "j":
        play_again = False

print(f"Tak for spillet, {player_name}!")
```

</Solution>

## Færdig!

Tillykke! Du har bygget et helt spil fra bunden. Her er nogle idéer til at lege videre:

- Lav tallene større eller mindre, eller lad spilleren vælge sværhedsgraden.
- Giv spilleren et maksimalt antal forsøg.
- Gem den bedste score.
- Sammenlign dit spil med en vens, og del dine bedste beskeder.

## Det hele samlet

Her er et eksempel på et spil med **alt**, hvad du har lært, samlet i ét program: funktion, spilløkke, tilfældigt tal, tilfældige beskeder, tæl forsøg, varmt og koldt, tid og spil igen. Din egen version må gerne se helt anderledes ud!

```python.run
import random
import time

not_a_number_messages = [
    "Det ved du bedre!",
    "Kom nu, jeg er ikke født i går.",
    "Du kan ikke narre mig. Det er slet ikke et tal!",
]
too_high_messages = ["Det er for højt!", "Hov, lidt lavere!", "Av, det var for stort!"]
too_low_messages = ["Det er for lavt!", "Prøv med noget større!", "Du skal højere op!"]
correct_messages = ["Fantastisk!", "Du er en mester!", "Hurra, du fandt det!"]

def get_numeric_guess():
    guess = ""
    while not guess.isnumeric():
        guess = input("Hvad gætter du på? ")
        if not guess.isnumeric():
            print(random.choice(not_a_number_messages))
    return int(guess)

player_name = input("Hvad hedder du? ")
print(f"Velkommen til Gæt et tal, {player_name}!")

play_again = True
while play_again:
    print("Jeg tænker på et tal mellem 1 og 100.")
    secret = random.randint(1, 100)
    attempts = 0
    start = time.time()

    has_guessed_correctly = False
    while not has_guessed_correctly:
        guess = get_numeric_guess()
        attempts += 1

        if guess == secret:
            seconds = round(time.time() - start)
            print(random.choice(correct_messages))
            print(f"{guess} var det rigtige tal! Du brugte {attempts} forsøg og {seconds} sekunder.")
            if seconds < 20:
                print("Lynhurtigt!")
            elif seconds < 60:
                print("Flot tempo!")
            else:
                print("Du tog dig god tid.")
            has_guessed_correctly = True
        else:
            if guess < secret:
                print(random.choice(too_low_messages))
            else:
                print(random.choice(too_high_messages))

            distance = abs(guess - secret)
            if distance <= 5:
                print("Du brænder!")
            elif distance <= 15:
                print("Det bliver varmere!")
            elif distance <= 40:
                print("Lunkent...")
            else:
                print("Hold da op, du er helt ude i skoven!")

    answer = input("Vil du spille igen? (j/n) ")
    if answer != "j":
        play_again = False

print(f"Tak for spillet, {player_name}!")
```

</Solution>

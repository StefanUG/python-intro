Hvor mange gæt skulle du bruge for at finde tallet? Lad os få spillet til at tælle og fortælle dig det til sidst.

## En tæller

En tæller er bare en variabel, der starter på 0, og som vi lægger 1 til, hver gang noget sker:

```python
attempts = 0
attempts = attempts + 1
```

Linjen `attempts = attempts + 1` læses sådan: "tag den gamle værdi af `attempts`, læg 1 til, og gem det i `attempts` igen."

Det kan skrives kortere med `+=`:

```python
attempts += 1
```

Det betyder det samme.

## Fortæl resultatet

Når spilleren har gættet rigtigt, kan du bruge tælleren i en besked:

```python
print(f"Du brugte {attempts} forsøg!")
```

:::tip[Opgave]
Ret din kode i kodeboksen nederst:

1. Lav variablen `attempts` og sæt den til `0` før løkken.
2. Læg 1 til `attempts`, hver gang spilleren har lavet et gyldigt gæt.
3. Når gættet er rigtigt, skal spillet fortælle, hvor mange forsøg der skulle til.

Tænk over, hvor i løkken `attempts += 1` skal stå. Skal et gæt som `banan` tælle med?
:::

```python.run
# Byg et 'Gæt et tal'-spil med det, du har lært ovenfor.
# Skriv din egen kode her
```

:::tip[Hint]
Linjen `attempts += 1` skal stå lige efter, du har fanget et gæt med `get_numeric_guess()`. Funktionen spørger, til gættet er gyldigt, så kun rigtige gæt bliver tælt.
:::

<Solution>

```python.run
import random

def get_numeric_guess():
    guess = ""
    while not guess.isnumeric():
        guess = input("Hvad gætter du på? ")
        if not guess.isnumeric():
            print("Det er ikke et tal, prøv igen.")
    return int(guess)

player_name = input("Hvad hedder du? ")
print(f"Velkommen til Gæt et tal, {player_name}!")
print("Jeg tænker på et tal mellem 1 og 100.")

secret = random.randint(1, 100)
attempts = 0

has_guessed_correctly = False
while not has_guessed_correctly:
    guess = get_numeric_guess()
    attempts += 1

    if guess == secret:
        print(f"Rigtigt! Du brugte {attempts} forsøg.")
        has_guessed_correctly = True
    elif guess < secret:
        print("Tallet er højere.")
    else:
        print("Tallet er lavere.")
```

</Solution>

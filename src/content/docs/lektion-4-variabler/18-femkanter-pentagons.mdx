:::tip[Hint]

Sæt `length` til 100. En femkant har 5 sider, så både den indre løkke og drejningen bruger 5.
:::

<Solution>

Sæt længden til 100 og brug 5 sider i den indre løkke.

```python.run
from turtle import *
import random

penup()
goto(0, -150)
pendown()

color_names = ["green", "blue", "orange", "red", "purple"]

def random_color():
    return random.choice(color_names)

length = 100

for j in range(5):
    color(random_color())
    for i in range(6):
        forward(length)
        left(360 / 5)
    forward(length)

done()
```

</Solution>

## Mere om variabler

You've just learned one great way to use a variable...as a constant!
When you use a variable as a constant, you are setting a value one time, 
then using that **same** value multiple times in your program without 
changing it after you click "Run".

---

In the next part of the series, you will write code with variables that **do** change inside the program.

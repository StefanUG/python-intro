## Kunstner: Variabler Opgave 10


```python.run
from turtle import *

# Dette gør så den starter længere nede
penup()
goto(-100,-150)
pendown()


sides = 4

for i in range( sides ):
  forward( 100 )
  left( 360 / sides )

done()
```

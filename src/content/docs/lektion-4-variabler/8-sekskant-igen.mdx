## Husk hvordan man dividerer

    360 / sides

## Kunstner: Variabler Opgave 8


```python.run
from turtle import *

# Dette gør så den starter længere nede
penup()
goto(-100,-150)
pendown()


sides = ???

for i in range( ? ):
  forward( 150 )
  left( 360 / ? )

done()
```

:::tip[Hint]

Sæt `sides` til 6. Brug samme variabel i både løkken og formlen `360 / sides`.
:::

<Solution>

Skift kun sides til 6 for at få en sekskant.

```python.run
from turtle import *

penup()
goto(-100, -150)
pendown()

sides = 6

for i in range(sides):
    forward(150)
    left(360 / sides)

done()
```

</Solution>

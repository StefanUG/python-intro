## Kunstner: Variabler Opgave 8

Nu skal du bare ændre variablen `length` for at ændre størrelsen på trekanterne.

<img src={import.meta.env.BASE_URL + "images/artist-variables/8-opdater-variabel.png"} alt="8. Opdater din variabel" class="solution-image" />


```python.run
from turtle import *

penup()
goto(-175, 100)
pendown()

def jump(l):
  penup()
  forward(l)
  pendown()

length = 50

for triangles in range(3):
  for sides in range(3):
    forward(length)
    left(120)
  jump(length)
  right(90)
  jump(length)
  left(90)
for triangles in range(3):
  for sides in range(3):
    forward(length)
    left(120)
  jump(length)
  left(90)
  jump(length)
  right(90)

done()
```


<Solution>

Ændre værdien af variablen `length` til 60.

```python.run
from turtle import *

penup()
goto(-175, 100)
pendown()

def jump(l):
  penup()
  forward(l)
  pendown()

length = 60

for triangles in range(3):
  for sides in range(3):
    forward(length)
    left(120)
  jump(length)
  right(90)
  jump(length)
  left(90)
for triangles in range(3):
  for sides in range(3):
    forward(length)
    left(120)
  jump(length)
  left(90)
  jump(length)
  right(90)

done()
```

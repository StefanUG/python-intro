```python.run
from turtle import *
import random

speed(0)

color_names = ["green", "blue", "orange", "red", "purple"]

def random_color(): return random.choice(color_names)

penup()
goto(-20,20)
pendown()


sides = 8
length = 200 / sides

for i in range(sides):
  for j in range(sides):
    for k in range(sides):
      forward(length)
      right(360/sides)
    forward(length)
    left(360/sides)
  forward(length)
  right(360/sides)


done()
```

<Solution>

Eksempel på fri leg med farver og tre indlejrede løkker:

```python.run
from turtle import *
import random

speed(0)
shape("turtle")

color_names = ["green", "blue", "orange", "red", "purple"]

def random_color():
    return random.choice(color_names)

penup()
goto(-20, 20)
pendown()

sides = 8
length = 200 / sides

for i in range(sides):
    color(random_color())
    for j in range(sides):
        for k in range(sides):
            forward(length)
            right(360 / sides)
        forward(length)
        left(360 / sides)
    forward(length)
    right(360 / sides)

done()
```

</Solution>

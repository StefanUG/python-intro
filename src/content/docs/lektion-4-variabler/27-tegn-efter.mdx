<Solution>

Løsningsforslag:

```python.run
from turtle import *
import random

color_names = ["green", "blue", "orange", "red", "purple"]

def random_color(): return random.choice(color_names)

length = 50

def skipdown():
  right(180)
  penup()
  forward(length/2)
  left(90)
  pendown()

for rows in range(3):
  for square in range(3):
    for side in range(5):
      forward(length)
      left(90)
    skipdown()
  penup()
  left(180)
  forward(length * 3.5)
  right(90)
  forward(length / 2)
  right(90)
  pendown()


done()
```

</Solution>


<Solution>

Et eksempel-inspireret mønster med farver og mange gentagelser:

```python.run
from turtle import *
import random

speed(0)
shape("turtle")

color_names = ["green", "blue", "orange", "red", "purple"]

def random_color():
    return random.choice(color_names)

penup()
goto(0, 0)
pendown()

for i in range(36):
    color(random_color())
    for j in range(5):
        forward(120)
        right(72)
    right(10)

done()
```

</Solution>

:::

```python.run
from turtle import *

penup()
goto(-75, -55)
pendown()

# Skriv koden herunder til at lave en 150 pixel trekant


done()
```


<Solution>

Du skal ændre koden, så den tegner firkanter i stedet for trekanter. Sørg for, at firkanterne har 80 pixel sider, og at kunstneren hopper 80 pixel frem og ned mellem hver firkant.

```python.run
from turtle import *

penup()
goto(-75, -55)
pendown()

length = 150

for triangle in range(1):
  for side in range(3):
    forward(length)
    left(120)

done()
```

</Solution>

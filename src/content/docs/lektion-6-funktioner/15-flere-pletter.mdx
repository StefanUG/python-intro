<Solution>

Vi genbruger den samme funktion to gange - én gang for hver plet med afgrøder.

```python.run requires="codingpirates-maze"
from maze import Puzzle, Harvester

maze = Puzzle.from_file("courseE_farmer_functions2b_2024")
farmer: Harvester = maze.player

def check_square_for_corn():
    if farmer.has_corn():
        farmer.pick_corn()

while not farmer.has_pumpkin():
    check_square_for_corn()
    farmer.forward()
farmer.pick_pumpkin()
farmer.left()
farmer.forward()
farmer.forward()
farmer.left()
while not farmer.has_pumpkin():
    check_square_for_corn()
    farmer.forward()
farmer.pick_pumpkin()

Puzzle.done()
```

</Solution>

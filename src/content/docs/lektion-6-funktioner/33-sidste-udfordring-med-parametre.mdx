*"Salathoved, kan du klare denne sidste test? Giv den alt, hvad du har!"*

Den store finale for denne lektion! Her skal høstmanden samle majs, græskar **og** salat - alt sammen med én genbrugelig funktion.

:::tip[Udfordring]
Brug én `for`-løkke inde i en funktion til at samle alle grøntsagerne i rækken. Lad `length`-parameteren styre, hvor langt løkken tæller. Gør dit program så kort som muligt ved at bruge endnu en `for`-løkke udenfor funktionen.

Held og lykke!

Sidder du fast? Du kan prøve at løse opgaven med blokke på [code.org](https://studio.code.org/s/coursef-2017/lessons/24/levels/11).

---
Her er de byggeklodser, du kan bruge i din kode:
```
farmer.forward() # limit: 7
farmer.right()
farmer.left()
farmer.pick_pumpkin() # limit: 1
farmer.pick_corn() # limit: 1
farmer.pick_lettuce() # limit: 1
for counter2 in range(1, 7):
    # Gør dette
if farmer.has_corn():
    # Gør dette
```

```python.run requires="codingpirates-maze"
from maze import Puzzle, Harvester

maze = Puzzle.from_file("courseF_bee_fwp_challenge2")
farmer: Harvester = maze.player

def pick_row(length):
    farmer.left()
    for counter in range(1, length + 1):
        farmer.forward()
        for i in range(counter):
            farmer.pick_corn()
    for i in range(length):
        farmer.backward()
    farmer.right()

# When run
farmer.forward()
pick_row(1)

# Keep this
Puzzle.done()
```

:::tip[Hint]
Funktionen kan allerede plukke majs i et trappemønster. Erstat den inderste løkke (`for i in range(counter): farmer.pick_corn()`) med tre `if`-tjek for majs, græskar og salat. Erstat så det ene kald for enden med en `for counter2 in range(1, 7):`-løkke, der flyver frem og kalder `pick_row(counter2)` for hver række.
:::

<Solution>

To løkker arbejder sammen: den ydre (`counter2`) styrer, hvor langt frem høstmanden flyver på hovedstien, og hvor lang den næste række er. Den indre (inde i `pick_row`) går ind i selve rækken, og endnu en løkke tjekker for alle tre afgrøder det rigtige antal gange ved hvert skridt.

```python.run requires="codingpirates-maze"
from maze import Puzzle, Harvester

maze = Puzzle.from_file("courseF_bee_fwp_challenge2")
farmer: Harvester = maze.player

def pick_row(length):
    farmer.left()
    for counter in range(1, length + 1):
        farmer.forward()
        for i in range(counter):
            if farmer.has_corn():
                farmer.pick_corn()
            if farmer.has_pumpkin():
                farmer.pick_pumpkin()
            if farmer.has_lettuce():
                farmer.pick_lettuce()
    for i in range(length):
        farmer.backward()
    farmer.right()

for counter2 in range(1, 7):
    farmer.forward()
    pick_row(counter2)

Puzzle.done()
```

</Solution>

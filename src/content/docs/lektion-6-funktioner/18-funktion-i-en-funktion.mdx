## En ny ting: funktioner kan kalde andre funktioner!

Lagde du mærke til, hvor meget gentaget kode der var i sidste opgave? Vi kan spare plads ved at pakke det hele ind i én ny funktion, der kalder de andre to funktioner for os - `pick_along_path()`.

```python
def pick_along_path():
    while not farmer.has_pumpkin():
        check_square_for_corn()
        farmer.forward()
    get_all_pumpkins()
```

Det er en funktion, der selv bruger andre funktioner indeni - helt ligesom man kan gøre i løkker og `if`-sætninger!

:::tip[Opgave]
Brug `pick_along_path()` til at løse opgaven igen med færre byggeklodser.

Sidder du fast? Du kan prøve at løse opgaven med blokke på [code.org](https://studio.code.org/s/coursee-2024/lessons/17/levels/7).

---
Her er de byggeklodser, du kan bruge i din kode:
```
farmer.forward()
farmer.right()
farmer.left()
pick_along_path()
```
:::

<Solution>

Med `pick_along_path()` kan vi erstatte hele den gentagne kode med bare ét funktionskald for hver plet.

```python.run requires="codingpirates-maze"
from maze import Puzzle, Harvester

maze = Puzzle.from_file("courseE_farmer_functions3c1_2024")
farmer: Harvester = maze.player

def get_all_pumpkins():
    while farmer.has_pumpkin():
        farmer.pick_pumpkin()

def check_square_for_corn():
    if farmer.has_corn():
        farmer.pick_corn()

def pick_along_path():
    while not farmer.has_pumpkin():
        check_square_for_corn()
        farmer.forward()
    get_all_pumpkins()

pick_along_path()
farmer.left()
farmer.forward()
farmer.forward()
farmer.left()
pick_along_path()
farmer.forward()
farmer.right()
pick_along_path()

Puzzle.done()
```

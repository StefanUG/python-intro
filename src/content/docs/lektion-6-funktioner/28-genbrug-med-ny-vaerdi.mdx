:::tip[Opgave]
Funktionen har nu en `length`-parameter. Brug den til at samle nektaren - kald den med en ny værdi for hver række.

Sidder du fast? Du kan prøve at løse opgaven med blokke på [code.org](https://studio.code.org/s/coursef-2017/lessons/24/levels/5).

---
Her er de byggeklodser, du kan bruge i din kode:
```
bee.forward()
bee.right()
bee.left()
rowOfNectar()
```
:::

<img src={import.meta.env.BASE_URL + "images/lektion-6-funktioner/28-genbrug-med-ny-vaerdi.png"} alt="28-genbrug-med-ny-vaerdi.png" class="solution-image" />

```python.run requires="codingpirates-maze"
from maze import Puzzle, BeePlayer

maze = Puzzle.from_file("courseF_bee_fwp5")
bee: BeePlayer = maze.player

def rowOfNectar(length):
    for i in range(length):
        bee.forward()
        if bee.at_flower():
            bee.get_nectar()

# When run
rowOfNectar(2)

# Keep this
Puzzle.done()
```

:::tip[Hint]
Der er allerede kaldt én gang med `2`. Tilføj fem kald mere med de rigtige længder, og husk at dreje mellem rækkerne.
:::

<Solution>

Vi kalder den samme funktion seks gange, hver gang med en ny værdi for `length`, alt efter hvor lang den næste række er.

```python.run requires="codingpirates-maze"
from maze import Puzzle, BeePlayer

maze = Puzzle.from_file("courseF_bee_fwp5")
bee: BeePlayer = maze.player

def rowOfNectar(length):
    for i in range(length):
        bee.forward()
        if bee.at_flower():
            bee.get_nectar()

rowOfNectar(2)
bee.left()
rowOfNectar(7)
bee.right()
rowOfNectar(4)
bee.right()
rowOfNectar(2)
bee.right()
rowOfNectar(2)
bee.left()
rowOfNectar(5)

Puzzle.done()
```

</Solution>

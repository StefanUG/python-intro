<Solution>

Vi genbruger den samme `garden_square()`-funktion - det er hele pointen med funktioner!

```python.run requires="codingpirates-maze"
from maze import Puzzle, Harvester

maze = Puzzle.from_file("courseE_farmer_functions8a1_2024")
farmer: Harvester = maze.player

def garden_square():
    for i in range(4):
        farmer.forward()
        farmer.pick_lettuce()
        farmer.forward()
        farmer.right()

garden_square()
farmer.right()
garden_square()

Puzzle.done()
```

</Solution>

Samme funktion som sidst - men nu skal rækkerne tælles **baglæns**. Det kan du gøre ved at give `range(...)` tre argumenter: start, stop og skridt.

```python
for counter in range(5, 0, -1):
    # tæller 5, 4, 3, 2, 1
```

:::tip[Opgave]
Brug din `rowOfNectarOrHoney(length)`-funktion igen, denne gang med rækkerne i faldende rækkefølge.

Sidder du fast? Du kan prøve at løse opgaven med blokke på [code.org](https://studio.code.org/s/coursef-2017/lessons/24/levels/8).

```python.run requires="codingpirates-maze"
from maze import Puzzle, BeePlayer

maze = Puzzle.from_file("courseF_bee_fwp8")
bee: BeePlayer = maze.player

def rowOfNectarOrHoney(length):
    for i in range(length):
        bee.forward()
        if bee.at_flower():
            bee.get_nectar()
        if bee.at_honeycomb():
            bee.make_honey()

for counter in range(5, 0, -1):
    rowOfNectarOrHoney(counter)
    bee.right()

Puzzle.done()
```

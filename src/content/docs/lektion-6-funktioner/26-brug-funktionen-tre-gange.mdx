Tid til at sætte funktionen på prøve! Lad os se, om den gør det nemmere at samle nektar fra tre rækker.

:::tip[Opgave]
Brug `rowOfNectar()` tre gange til at tjekke alle tre rækker.

Sidder du fast? Du kan prøve at løse opgaven med blokke på [code.org](https://studio.code.org/s/coursef-2017/lessons/24/levels/3).

---
Her er de byggeklodser, du kan bruge i din kode:
```
bee.forward()
bee.right()
bee.left()
rowOfNectar()
def rowOfNectar():

```
:::

```python.run requires="codingpirates-maze"
from maze import Puzzle, BeePlayer

maze = Puzzle.from_file("courseF_bee_fwp3")
bee: BeePlayer = maze.player

def rowOfNectar():
    for i in range(7):
        bee.forward()
        if bee.at_flower():
            bee.get_nectar()

# When run
rowOfNectar()

# Keep this
Puzzle.done()
```

:::tip[Hint]
`rowOfNectar()` er allerede kaldt én gang. Tilføj drejninger og to kald mere, så alle tre rækker bliver tjekket.
:::

```python.run requires="codingpirates-maze"
from maze import Puzzle, BeePlayer

maze = Puzzle.from_file("courseF_bee_fwp3")
bee: BeePlayer = maze.player

def rowOfNectar():
    for i in range(7):
        bee.forward()
        if bee.at_flower():
            bee.get_nectar()

rowOfNectar()
bee.right()
bee.forward()
bee.forward()
bee.right()
rowOfNectar()
bee.left()
bee.forward()
bee.forward()
bee.left()
rowOfNectar()

Puzzle.done()
```

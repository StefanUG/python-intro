<Solution>

Samme opskrift som sidst, bare gentaget én gang mere for den ekstra plet.

```python.run requires="codingpirates-maze"
from maze import Puzzle, Harvester

maze = Puzzle.from_file("courseE_farmer_functions3c_2024")
farmer: Harvester = maze.player

def get_all_pumpkins():
    while farmer.has_pumpkin():
        farmer.pick_pumpkin()

def check_square_for_corn():
    if farmer.has_corn():
        farmer.pick_corn()

while not farmer.has_pumpkin():
    check_square_for_corn()
    farmer.forward()
get_all_pumpkins()
farmer.left()
farmer.forward()
farmer.forward()
farmer.left()
while not farmer.has_pumpkin():
    check_square_for_corn()
    farmer.forward()
get_all_pumpkins()
farmer.forward()
farmer.right()
while not farmer.has_pumpkin():
    check_square_for_corn()
    farmer.forward()
get_all_pumpkins()

Puzzle.done()
```

</Solution>

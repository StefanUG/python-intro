## Nye ting høstmanden kan

I denne lektion møder vi høstmanden igen, og lærer nogle nye ting, den kan:

```python
farmer.forward()
farmer.right()
farmer.left()
farmer.pick_corn()     # høster majs
farmer.pick_pumpkin()  # høster et græskar
farmer.pick_lettuce()  # høster et salathoved
```

Den kan også tjekke, om der er mere sti foran med `farmer.path_ahead()`, ligesom vi så i Lektion 5.

:::tip[Opgave]
Hjælp høstmanden med at nå frem til græskarret og høste det.

Sidder du fast? Du kan prøve at løse opgaven med blokke på [code.org](https://studio.code.org/s/coursee-2024/lessons/17/levels/2).

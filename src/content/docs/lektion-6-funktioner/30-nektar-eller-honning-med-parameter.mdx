```python.run requires="codingpirates-maze"
def rowOfNectarOrHoney(length):
    for i in range(length):
        bee.forward()
        if bee.at_flower():
            bee.get_nectar()

# When run
rowOfNectarOrHoney(?)

# Keep this
Puzzle.done()
```

:::tip[Hint]
Tilføj et ekstra tjek i funktionen: `if bee.at_honeycomb(): bee.make_honey()`, ved siden af tjekket for blomster. Erstat så placeholderen med en `for`-løkke, der kalder funktionen med stigende længder.
:::

<Solution>

Vi udvider funktionen med endnu et tjek, så den håndterer både blomster og honningtavler, og drejer bien til venstre før hver række.

```python.run requires="codingpirates-maze"
from maze import Puzzle, BeePlayer

maze = Puzzle.from_file("courseF_bee_fwp7")
bee: BeePlayer = maze.player

def rowOfNectarOrHoney(length):
    for i in range(length):
        bee.forward()
        if bee.at_flower():
            bee.get_nectar()
        if bee.at_honeycomb():
            bee.make_honey()

for counter in range(1, 7):
    bee.left()
    rowOfNectarOrHoney(counter)

Puzzle.done()
```

</Solution>

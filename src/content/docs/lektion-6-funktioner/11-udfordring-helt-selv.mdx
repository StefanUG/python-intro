<Solution>

Vi kombinerer det, vi har lært om `if/else` fra forrige lektion med funktioner: funktionen besøger 3 blomster/honningtavler ad gangen, tjekker hvad der er, og gør det rigtige.

```python.run requires="codingpirates-maze"
from maze import Puzzle, BeePlayer

maze = Puzzle.from_file("courseE_bee_functions_challenge1")
bee: BeePlayer = maze.player

def get_3_nectar_or_honey():
    for i in range(3):
        bee.forward()
        bee.forward()
        bee.left()
        bee.forward()
        if bee.at_flower():
            bee.get_nectar()
        else:
            bee.make_honey()
        bee.backward()
        bee.right()

get_3_nectar_or_honey()
for i in range(2):
    bee.forward()
    bee.right()
    bee.forward()
get_3_nectar_or_honey()

Puzzle.done()
```

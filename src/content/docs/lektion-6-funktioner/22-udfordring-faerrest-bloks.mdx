<Solution>

Vi bygger et helt "tårn" af funktioner: `pumpkin_square()` kalder `pick_along_path()`, som igen kalder `check_square_for_corn()` og `get_all_pumpkins()`.

```python.run requires="codingpirates-maze"
from maze import Puzzle, Harvester

maze = Puzzle.from_file("courseE_farmer_functions10a1_2024")
farmer: Harvester = maze.player

def get_all_pumpkins():
    while farmer.has_pumpkin():
        farmer.pick_pumpkin()

def check_square_for_corn():
    if farmer.has_corn():
        farmer.pick_corn()

def pick_along_path():
    while not farmer.has_pumpkin():
        check_square_for_corn()
        farmer.forward()
    get_all_pumpkins()

def pumpkin_square():
    for i in range(4):
        pick_along_path()
        farmer.right()

pumpkin_square()

Puzzle.done()
```

</Solution>

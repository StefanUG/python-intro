<Solution>

Farmer følger stien så langt den kan, går ét skridt tilbage igen, fylder hullet og fjerner bunken der, og drejer, før den fortsætter.

```python.run requires="codingpirates-maze"
from maze import Puzzle, Farmer

maze = Puzzle.from_file("courseD_farmer_while_challenge1_2025")
farmer: Farmer = maze.player

while farmer.path_ahead():
    while farmer.path_ahead():
        farmer.forward()
    farmer.backward()
    while farmer.at_hole():
        farmer.fill()
    while farmer.at_pile():
        farmer.remove()
    farmer.right()

Puzzle.done()
```

</Solution>

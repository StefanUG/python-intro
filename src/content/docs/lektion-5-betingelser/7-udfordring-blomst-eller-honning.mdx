Bien går 3 felter frem, tjekker if/else, og drejer - gentaget 4 gange.

```python.run requires="codingpirates-maze"
from maze import Puzzle, BeePlayer

maze = Puzzle.from_file("courseD_bee_conditionals8_2025")
bee: BeePlayer = maze.player

for i in range(4):
    for i in range(3):
        bee.forward()
    if bee.at_flower():
        bee.get_nectar()
    else:
        bee.make_honey()
    bee.right()

Puzzle.done()
```

<Solution>

```python.run requires="codingpirates-maze"
from maze import Puzzle, BeePlayer

maze = Puzzle.from_file("courseD_bee_conditionals10_2025")
bee: BeePlayer = maze.player

for i in range(7):
    bee.forward()
    if bee.at_flower():
        bee.get_nectar()
    else:
        bee.make_honey()

Puzzle.done()
```

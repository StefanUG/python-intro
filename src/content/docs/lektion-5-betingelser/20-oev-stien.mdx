Følg stien til enden, fjern bunken, og drej - gentaget 3 gange.

```python.run requires="codingpirates-maze"
from maze import Puzzle, Farmer

maze = Puzzle.from_file("courseD_farmer_while9_2025")
farmer: Farmer = maze.player

for i in range(3):
    while farmer.path_ahead():
        farmer.forward()
    farmer.remove()
    farmer.left()

Puzzle.done()
```

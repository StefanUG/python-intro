Alle opgaverne i dette kursus kan løses direkte her på siden - du behøver ikke installere noget. Men hvis du har lyst til at programmere derhjemme på din egen computer, kan du installere et "IDE".

## Hvad er et IDE?

IDE betyder "Integrated Development Environment" (udviklingsmiljø på dansk). Det er et program, man bruger til at skrive og køre kode i - lidt ligesom den grønne kodeboks her på siden, bare som et program på din computer.

- Søg efter enten **"PyCharm"** eller **"Visual Studio Code"**
  - PyCharm er lavet af JetBrains
  - Visual Studio Code er lavet af Microsoft
- Download et af dem
- Installer det

## Hent kode projektet

Øvelserne ligger samlet i et projekt på GitHub, som du skal hente ned til din computer:

- Gå til [github.com/StefanUG](https://github.com/StefanUG)
- Under "Repositories" find **"code-org-python"**
- Download den seneste "release" (i højre side) - vælg enten `.zip` (Windows) eller `.tar.gz` (Mac)
- Pak filen ud (unzip)

## Sæt Visual Studio Code op

Hvis du valgte Visual Studio Code, er der et par ekstra skridt, før du kan køre Python-kode:

1. **Installer Python** - gå til [python.org/downloads](https://www.python.org/downloads/), og installer den nyeste version til din computer.
2. **Installer Python-udvidelsen** - åbn Extensions-panelet i VS Code (det firkantede ikon i venstre side, eller `Cmd+Shift+X` / `Ctrl+Shift+X`), søg efter **"Python"** (udvidelsen fra Microsoft), og klik **Install**.
3. **Åbn den udpakkede mappe** - vælg **File → Open Folder...** og find den mappe, du pakkede ud. Vigtigt! Det skal være mappen, der indeholder filen `README.md`.
4. **Opret et Python-miljø** - VS Code spørger typisk automatisk, om den skal oprette et "Python Environment" til projektet - sig **ja** til det. Spørger den ikke selv, kan du åbne Command Palette (`Cmd+Shift+P` / `Ctrl+Shift+P`) og vælge **Python: Create Environment**.

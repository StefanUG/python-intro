## Level 7 i Python

Husk hvordan en løkke ser ud

```python
for i in range(???):
```

HUSK du kan bruge Tab og Shift-Tab for at indrykke og rykke ud

Gør det selv færdigt

```python.run
from turtle import *

forward(100)
back(100)
right(90)

done()
```

:::tip[Hint]

```python
for i in range(???):
  forward(100)
  back(100)
  right(90)
```
:::

<Solution>

Ved at lave et kryds med 4 linjer kan man få et plustegn.

```python.run
from turtle import *

for i in range(4):
  forward(100)
  back(100)
  right(90)

done()
```
</Solution>

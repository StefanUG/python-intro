## Intro til Turtle

Turtle er navnet på en komponent i Python som kan bruges til at tegne med. Den kan styres på samme måde som Elsa i Hour of Code.

Her de dele vi skal bruge til at komme i gang.

Først skal vi importere komponenten. Så vi kan bruge dens funktioner eller "blokke":

```python
from turtle import *
```

Så kan vi kalde nogle funktioner ligesom blokke:

```python
forward(100)
right(90)
```

Til sidst skal vi kalde en funktion for at holde vinduet åbnet. Det er ikke så 
vigtigt i browseren her, da tegningen forbliver, selv når programmet er færdigt.
Men hvis du kører det lokalt på din computer, så skal du huske denne del til sidst.

```python
done()
```


Du vil nogle gange se kommentarer i koden. De starter med en `#` og fortæller 
Python at linien ikke er rigtig kode og derfor skal ignoreres.

```python
# Dette er en kommentar, som python er ligeglad med.
# Det kan gøre koden nemmere at læse
# eller benyttes til at fortælle jer hvor I skal skrive jeres kode.
```


## Lav et kvadrat med Turtle

Nu er det din tur. Prøv at lav et kvadrat ligesom i Hour of Code. 
Prøv at gøre koden færdig.

<img src={import.meta.env.BASE_URL + "images/elsa/1-3-else-and-turtle.png"} alt="1-3-else-and-turtle.png" class="solution-image" />

```python.run
from turtle import *

forward(100)
right(90)

# Lav en firkant, ligesom i Hour of Code

done()
```

:::tip[Genvejstaster]
Det smarte ved kode som tekst er at man nemt kan kopiere kode og sætte det ind igen. Det findes der genvejstaster til.

1. Marker noget tekst med Shift og piletasterne
2. kopier med Ctrl+C (Cmd+C på Mac)
3. flyt markøren til et andet sted, enten med piletasterne eller med musen
4. indsæt med Ctrl+V (Cmd+V på Mac)
:::

<Solution>

Gentag koden for at lave en firkant. Du skal bruge `forward` og `right` 4 gange.

```python.run
from turtle import *

forward(100)
right(90)
forward(100)
right(90)
forward(100)
right(90)
forward(100)
right(90)

done()
```
</Solution>

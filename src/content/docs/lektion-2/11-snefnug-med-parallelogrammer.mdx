## Opgave 11 i Python

<img src={import.meta.env.BASE_URL + "images/elsa/11-snefnug-af-parallelogrammer.png"} alt="11-snefnug-af-parallelogrammer.png" class="elsa-screenshot" />

```python.run
from turtle import *

for i in range(2):
    forward(100)
    right(60)
    forward(100)
    right(120)
right(???)

done()

```

<Solution>

Her gentager vi parallelogrammet 4 gange og drejer 90 grader mellem hver.

```python.run
from turtle import *

for i in range(4):
    for j in range(2):
        forward(100)
        right(60)
        forward(100)
        right(120)
    right(90)

done()
```

</Solution>

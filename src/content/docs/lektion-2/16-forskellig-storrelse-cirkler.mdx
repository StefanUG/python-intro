:::tip[Hint]

`circle(?)` tager størrelsen på cirklen som parameter. Brug først 50 og derefter 100.
:::

<Solution>

Først en lille cirkel og derefter en større cirkel.

```python.run
from turtle import *

circle(50)
circle(100)

done()
```

</Solution>

<Solution>

20 cirkler med 18 graders drejning giver et komplet mønster (20 * 18 = 360).

```python.run
from turtle import *

def hopfrem(trin):
  penup()
  forward(trin)
  pendown()

for i in range(20):
  circle(50)
  hopfrem(10)
  right(18)

done()
```

</Solution>

### Ekstra opgave

Flyt turtle opad, før vi starter, så er der mere plads.
Det kan vi gøre med `sety(y)` hvor `y` er et tal.

```python
penup()
sety(200)
pendown()
```
